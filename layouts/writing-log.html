How this is counted

Every number here is a difference between two git commits. For each commit that touched a Markdown file, the word count before is subtracted from the word count after, and the result is filed under that commit’s date. Two repositories feed it: this site, and my Obsidian vault, which has been tracked in git since August 2026 for exactly this purpose.

Front matter, code blocks and blockquotes are stripped before counting, so quoted source material is not counted as mine. Reading notes imported from Zotero and Readwise are excluded entirely. Posts drafted in the vault are counted on the day they were drafted, not the day they were published.

Two honest limitations. Rewriting a paragraph into a better paragraph of the same length is a real day’s work that registers as zero, because the measure is size rather than effort. And writing that predates its arrival in git — the older posts here were imported in bulk — is filed under the date in its front matter, which is the best record that exists.
