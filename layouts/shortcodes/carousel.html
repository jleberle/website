{{- /* Two call forms (Hugo shortcodes can't mix positional and named params): carousel "a.avif" "b.avif" positional — for carousels below the fold (the usual case); every slide lazy-loads. Each slide's alt text falls back to the humanized filename. carousel images="a.avif, b.avif" alts="A bull rider; Barrel racing" eager=true named — pass eager=true when the carousel is the topmost media on the page: the first slide then loads eagerly with fetchpriority="high" since it is the likely LCP element. Don't combine with a visible cover image (they'd compete for priority). alts is an optional, parallel list describing each image in order; it is SEMICOLON-separated (so alt text may contain commas). A slide with no matching entry falls back to the humanized filename. Only the named form can carry alt text — positional params can't be mixed with a named alts param. Images and their alt text are paired up front so slides, alt, and dots never drift out of alignment even if a filename fails to resolve. */ -}} {{- $names := .Params -}} {{- $eager := false -}} {{- $alts := slice -}} {{- if .IsNamedParams -}} {{- $names = split (.Get "images") "," -}} {{- $eager = eq (printf "%v" (.Get "eager")) "true" -}} {{- with .Get "alts" }}{{- $alts = split . ";" -}}{{- end -}} {{- end -}} {{- $slides := slice -}} {{- range $i, $name := $names -}} {{- with $.Page.Resources.GetMatch (strings.TrimSpace $name) -}} {{- $alt := "" -}} {{- if lt $i (len $alts) }}{{- $alt = strings.TrimSpace (index $alts $i) -}}{{- end -}} {{- $slides = $slides | append (dict "img" . "alt" $alt) -}} {{- end -}} {{- end -}}
{{- range $i, $s := $slides }} {{- $img := $s.img }} {{- $r := partial "responsive-img.html" (dict "resource" $img) }} {{- end }}
