{{- /* Multi-part post series. Set `series: "A Series Name"` in front matter on every part — a natural display name, same as tags/ categories, not a hyphenated slug (Hugo title-cases each word of the taxonomy term but won't turn hyphens into spaces). The same value on every part links them together automatically via the `series` taxonomy (hugo.yaml), ordered by date. No-op for posts with no series param or whose series has only one member. */ -}} {{- with .GetTerms "series" }} {{- $siblings := (index . 0).Pages.ByDate }} {{- if gt (len $siblings) 1 }} {{- $total := len $siblings }} {{- $currentNum := 0 }} {{- $page := $ }} {{- range $i, $p := $siblings }}{{ if eq $p.RelPermalink $page.RelPermalink }}{{ $currentNum = add $i 1 }}{{ end }}{{ end }} {{- /* Every part renders here, unlike related_posts.html's explicit 2-3 item cap, because this is wayfinding through a specific known list rather than a discovery aid — truncating it would mean a reader on part 12 could no longer jump to part 3. Past a handful of parts a flat list becomes a wall of links on every single page in the series, so a long run collapses behind the same
progressive-disclosure pattern already used for the table of contents (toc.html): the current part stays visible in the kicker either way, and the full list opens on demand instead of always being on the page. */ -}} {{- $long := gt $total 8 }}

All {{ $total }} parts {{- end }}
